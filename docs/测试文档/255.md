## 验证要点

| 检查项 | 预期 |
|--------|------|
| 代码块内 `#`（注释） | 不变蓝不加粗，纯色 |
| 代码块内 `**` / `*` / `~~` / `>` / `` ` `` / `-` / `1.` | 全部无任何效果，纯色 |
| 代码块内字符串 `"Jack"`、三引号 | 不变色 |
| 块外标题/粗体/斜体/列表/引用/分隔线/行内代码/链接 | 高亮正常，未受代码块过滤影响 |
| 块后新标题 | 重新高亮（过滤未泄漏到块外） |

建议看点：代码块内若有任一符号上色，就是遗漏；块外元素若没高亮就是过滤误伤。你在真机或截图上看到异常现象可反馈具体位置。
