## 人脸识别主要例程验证

### webcam_face_pose_ex例程

1. **例程的运行任务**

   实时摄像头人脸姿态估计与关键点标记系统

2. **主要技术和关键函数**

      1. cv::VideoCapture cap(0);: OpenCV 函数，初始化摄像头，0 通常代表默认的第一个摄像头。
      2. cap.set(cv::CAP_PROP_FRAME_WIDTH, 640); cap.set(cv::CAP_PROP_FRAME_HEIGHT, 480);: OpenCV 函数，设置摄像头捕获的图像分辨率为 640x480，降低分辨率以提高处理速度。
      3. frontal_face_detector detector = get_frontal_face_detector();: dlib 函数，加载内置的 HOG+SVM 前脸检测器。
      4. deserialize(...) / >> pose_model;: dlib 函数，反序列化并加载外部的 shape_predictor_68_face_landmarks.dat 模型文件，用于进行面部特征点预测。
      5. detector(cimg);: dlib 函数，在输入图像 cimg 上执行人脸检测，返回一个包含检测到的人脸区域 (rectangle) 的向量。
      6. pose_model(cimg, faces[i]);: dlib 函数，对指定的人脸区域 faces[i] 和图像 cimg 应用形状预测器，返回一个包含68个关键点位置的 full_object_detection 对象。
      7. cv_image<bgr_pixel> cimg(temp);: dlib 函数，将 OpenCV 的 cv::Mat 格式图像 temp 包装成 dlib 可以处理的 cv_image 格式。
      8. render_face_detections(shapes): dlib 函数，生成一个可视化对象，用于在图像上绘制 shapes 中存储的所有人脸关键点。
      9. win.add_overlay(...): dlib 函数，将渲染好的关键点覆盖到图像窗口上进行显示。
      10. high_resolution_clock::now() / duration_cast: C++ 标准库 (chrono)，用于高精度计时，计算帧率 (FPS)。
      11. std::this_thread::sleep_for(...): C++ 标准库 (thread)，让主线程短暂休眠，以控制显示循环的速度，避免过度消耗 CPU。
      12. frame_count % SKIP_FRAMES == 0: 核心优化逻辑，通过判断帧计数器是否为设定间隔的倍数，实现“跳帧检测”，即并非每一帧都进行耗时的人脸检测和关键点预测，而是每隔几帧执行一次，以换取更高的整体流畅度。

### dnn_face_recognition_ex

1. **例程的运行任务**

      在一个给定的图片中，检测所有的人脸，并将这些脸按照“看起来是同一个人”进行分组（聚类）。

2. **人脸检测和人脸识别的过程**

      1. get_frontal_face_detector(): 加载并返回一个快速的人脸检测器，用于定位图像中人脸的大致区域。
      2. deserialize(...) (多次使用): 从磁盘文件加载预训练的机器学习模型数据到内存中的变量（sp, net）。
      3. load_image(): 从指定文件路径加载图像到 dlib 的 matrix<rgb_pixel> 数据结构中。
      4. sp(img, face): 对给定图像 img 中的 face 区域应用形状预测器，返回一个包含5个人脸关键点的 full_object_detection 对象。
      5. extract_image_chip(): 根据 shape（关键点信息）对原始图像 img 进行几何变换和裁剪，生成一个标准化、对齐的 face_chip。
      6. net(faces): 将标准化后的人脸图像 faces 输入到深度神经网络 net 中，批量计算出对应的128维特征向量集合 face_descriptors。
      7. length(...) < 0.6: 计算两个人脸特征向量之间的欧氏距离，并与阈值0.6比较，判断是否为同一个人。
      8. chinese_whispers(): 基于人脸间的相似性（连接边），执行图聚类算法，将所有人脸自动分组。
      9. jitter_image(): （可选但能提升精度）通过对单张人脸图像进行随机的微小变形（旋转、缩放、平移、翻转）生成多张略有差异的图像，再计算它们的平均特征向量作为最终描述符，以增强模型的鲁棒性。

## 实时人脸检测

### 代码

* `capture_detect.cpp`

```c++
// capture_detect_with_coords.cpp
#include <opencv2/opencv.hpp>
#include <dlib/opencv.h>
#include <dlib/image_processing/frontal_face_detector.h>
#include <dlib/gui_widgets.h>
#include <iostream>

#define DETECTION_INTERVAL 10  // 每10帧检测一次
#define DOWNSAMPLE_FACTOR 0.5  // 缩放因子，例如原图的一半大小
#define TARGET_FPS 15          // 目标帧率，例如 15 FPS

using namespace std;

int main() {
    int frame_count = 0;

    cv::VideoCapture cap(0);
    if (!cap.isOpened()) {
        cerr << "无法打开摄像头" << endl;
        return -1;
    }

    // 设置摄像头参数以降低采集帧率和分辨率
    cap.set(cv::CAP_PROP_FPS, TARGET_FPS);
    double actual_fps = cap.get(cv::CAP_PROP_FPS);
    cout << "摄像头目标帧率: " << TARGET_FPS << ", 实际设置帧率: " << actual_fps << endl;

    dlib::image_window win;
    dlib::frontal_face_detector detector = dlib::get_frontal_face_detector();

    int original_width = static_cast<int>(cap.get(cv::CAP_PROP_FRAME_WIDTH));
    int original_height = static_cast<int>(cap.get(cv::CAP_PROP_FRAME_HEIGHT));
    cout << "摄像头分辨率: " << original_width << " x " << original_height << endl;

    while (true) {
        cv::Mat frame;
        cap >> frame;

        if (frame.empty()) {
            cerr << "捕获到空帧，退出..." << endl;
            break;
        }

        // 始终更新显示原图，保证视觉效果
        dlib::cv_image<dlib::bgr_pixel> original_dlib_img(frame);
        win.set_image(original_dlib_img);

        if (win.is_closed()) {
            break;
        }

        if (frame_count % DETECTION_INTERVAL == 0) {
            // --- 优化: 降低分辨率用于检测 ---
            cv::Mat small_frame;
            cv::resize(frame, small_frame, cv::Size(), DOWNSAMPLE_FACTOR, DOWNSAMPLE_FACTOR);
            dlib::cv_image<dlib::bgr_pixel> small_dlib_img(small_frame);

            // 在缩小的图像上进行检测
            std::vector<dlib::rectangle> small_faces = detector(small_dlib_img);

            // 将检测到的小图坐标映射回原图坐标
            std::vector<dlib::rectangle> faces_on_original;
            for (auto face : small_faces) {
                 long left = static_cast<long>(face.left() / DOWNSAMPLE_FACTOR);
                 long top = static_cast<long>(face.top() / DOWNSAMPLE_FACTOR);
                 long right = static_cast<long>(face.right() / DOWNSAMPLE_FACTOR);
                 long bottom = static_cast<long>(face.bottom() / DOWNSAMPLE_FACTOR);
                 faces_on_original.push_back(dlib::rectangle(left, top, right, bottom));
            }

            // 清除旧的覆盖层
            win.clear_overlay();

            // --- 新增: 打印检测到的人脸坐标 ---
            cout << "检测到 " << faces_on_original.size() << " 张人脸." << endl;
            for (size_t i = 0; i < faces_on_original.size(); ++i) {
                auto& face = faces_on_original[i];
                cout << "Face box " << i+1 << ": left=" << face.left() 
                     << ", top=" << face.top() 
                     << ", right=" << face.right() 
                     << ", bottom=" << face.bottom() << endl;
            }
            // --- 结束新增 ---

            // 在原图上添加人脸框覆盖层
            win.add_overlay(faces_on_original, dlib::rgb_pixel(255, 0, 0));
        }

        frame_count++;
    }

    cap.release();
    return 0;
}
```

## 实验总结

*本次实验遇到了哪些问题，如何解决的？*

1. **画面流畅度低，脸部检测卡顿，整体运行缓慢**

    优化：提高摄像头人脸检测流畅度
    1. 降低摄像头分辨率至640x480
    2. 跳帧处理（每2帧检测一次）
    3. 优化显示刷新率
    4. 添加性能统计信息

2. **程序无法准确找到模型，异常报错**
    
    使用绝对地址，
如:/home/ubt/practice/model/dlib_face_recognition_resnet_model_v1.dat

   1. 检查并修改CMakeLists.txt
   2. 使用以下指令编译
      ```
      cmake -B build
      cmake --build build
      ```
    3. 将无关代码删去或注释
