## 2.1 初识 ArkTS

**核心观点**：ArkTS 并不是一门全新的语言。由于 JavaScript 应用广泛，TypeScript 又使 JavaScript 更加严谨，华为选择在 **TypeScript 的基础**上开发 ArkTS，使已经具备 JavaScript 或 TypeScript 基础的开发者可以快速上手鸿蒙应用开发。

三者关系可以理解为演进链条：**JavaScript → TypeScript → ArkTS**。

### 2.1.1 JavaScript

- JavaScript 是 Web 前端开发中的一门编程语言，最初主要用于开发交互式的网页，实现网页中的各种交互效果，例如轮播图、选项卡、表单验证等。
- 随着技术的发展，JavaScript 的应用领域变得更加广泛，还可以用来开发服务器应用、桌面应用和移动应用。

### 2.1.2 TypeScript

- TypeScript 是微软（Microsoft）公司推出的一门开源编程语言，它是 **JavaScript 的超集（superset）**，意味着 TypeScript 包含 JavaScript 的所有特性，并在 JavaScript 的基础上新增了一些新特性，例如：
  - 静态类型检查
  - 更严格的语法规则
  - 接口（interface）
  - 泛型（generic）
- 使用 TypeScript 中的静态类型，开发者可在**编码阶段**发现并修复潜在的错误，减少代码在运行时出现错误的可能性。
- TypeScript 支持 ECMAScript 标准，编写的代码可以编译成 JavaScript 代码，从而在 JavaScript 的环境中运行。
- TypeScript 提供了更好的开发工具和更严格的代码检查，广泛应用于大型 Web 应用程序和框架中，提高大型应用的可维护性和可读性。

### 2.1.3 ArkTS

- ArkTS 是华为推出的一门为**构建高性能应用**而设计的编程语言。许多编程语言在设计之初未考虑移动设备，导致应用运行缓慢、低效、功耗大，因此针对移动环境的编程语言优化需求越来越大。
- ArkTS 专为解决这些问题而设计，聚焦于**提高运行效率**。
- ArkTS 保持 TypeScript 的大部分语法，为现有的 TypeScript 开发者实现无缝过渡，让移动开发者快速上手。
- **一大特性**：专注于**低运行时开销**。ArkTS 对 TypeScript 的动态类型特性施加了更严格的限制，以减少运行时开销，提高运行效率。通过取消动态类型特性，ArkTS 代码能更有效地在运行前被编译和优化，从而实现更快的应用启动和更低的功耗。

## 2.2 调试输出和注释

### 2.2.1 调试输出

- 在实际开发中，经常需要输出一些信息，从而方便调试程序。
- 在 ArkTS 中，使用 **`console.log()`** 语句可以进行调试输出，输出结果可以在 DevEco Studio 底部的“日志”面板中查看。

`console.log()` 语句的语法格式如下：

```typescript
console.log(参数1, 参数2, …);
```

**格式说明：**

- 小括号中的参数表示要输出的内容，可以传入 **1 个或多个**参数，多个参数使用**英文逗号**分隔。
- **第 1 个参数必须是字符串**，其余参数如果是其他类型数据则会被自动转为字符串。
- “…”用于在文档中说明在参数 2 的后面还可以写更多参数，实际编写代码时不用写“…”。
- 语句末尾的分号“;”表示**语句分隔符**，在它后面可以写下一条语句；通过换行的方式可以省略语句分隔符。

### 2.2.2 注释

- 注释用于对代码进行解释和说明，让代码阅读者更轻松地了解代码的设计逻辑、用途等。
- 在实际开发中，为提高代码可读性、方便维护和升级，可在编写代码时添加注释。
- **注释在程序解析时会被忽略。**

**1. 单行注释**

单行注释以 `//` 开始，到该行结束为止：

```typescript
console.log('你好');
// 调试输出
```

**2. 多行注释**

多行注释以 `/*` 开始，以 `*/` 结束：

```typescript
/*
调试输出
*/
console.log('你好');
```

## 2.3 变量、常量和数据类型

### 2.3.1 变量

- 变量是指程序在内存中申请的一块用来存放数据的空间，用于存储程序运行过程中产生的临时数据。例如，将两个数字相乘的结果保存到变量中，以便在后面的计算中使用。
- 使用变量时，需要先**声明变量**，之后可以为变量赋值，完成数据的存储。

**声明变量的语法格式：**

```typescript
let 变量名: 类型;
```

- `let` 是声明变量的关键字。
- 变量名是指变量的名称。
- 类型通常设置为数据类型、类或接口等。例如，字符串 `'a'` 对应的数据类型是 `string`，数字 `1` 对应的数据类型是 `number`。

**多类型变量：**

- ArkTS 允许一个变量有多种类型，将“类型”写成 “`类型1 | 类型2 | …`” 的形式即可。
  - 如：`string | number` 表示变量的值可以是字符串或数字。
- 但 **ArkTS 不支持 TypeScript 中的 `any` 类型**（`any` 表示任意类型）。为了提高代码的严谨性和运行效率，ArkTS **禁用了 `any` 类型**。

**变量的命名规则：**

1. 不能以数字开头，且不能包含 `+`、`-` 等运算符，如 `01user`、`user-02` 是非法的变量名。
2. **严格区分大小写**，如 `apple` 和 `Apple` 是两个不同的变量名。
3. 不能使用 ArkTS 中的**关键字**命名。关键字是被事先定义并赋予特殊含义的单词，例如 `let`、`if`、`while` 就是 ArkTS 中的关键字。

**变量命名建议（提高可读性）：**

1. 使用字母、数字、下划线或美元符号（`$`）命名，如 `score`、`set_name`、`$a`、`user01`。
2. 尽量做到“见其名知其义”，如 `age` 表示年龄、`num` 表示数字等。
3. 用下划线分隔多个单词（如 `show_message`）；或采用**驼峰命名法**（第 1 个单词首字母小写，后面的单词首字母大写，如 `leftHand`、`myFirstName`）。

**为变量赋值：**

```typescript
变量名 = 值;
```

声明变量与赋值写在同一行，称为**定义变量**或**初始化变量**：

```typescript
let 变量名: 类型 = 值;
```

- 在定义变量时，如果通过“值”可以自动推断出变量类型，则变量名后面的 `: 类型` 可以省略。

**一行声明多个变量：**

```typescript
let 变量名1: 类型, 变量名2: 类型, …;
let 变量名1: 类型 = 值1, 变量名2: 类型 = 值2;
```

**变量的使用示例：**

```typescript
// 声明变量student01并赋值为'小明'，设置类型
let student01: string = '小明';
// 声明变量student02并赋值为'小智'，省略类型
let student02 = '小智';
console.log(student01);
// 输出结果：小明
console.log(student02);
// 输出结果：小智
```

### 2.3.2 常量

- 常量是一种在程序运行过程中始终保持不变的数据，例如数学中的圆周率在程序中就可以保存为一个常量。
- 在 ArkTS 中，常量分为**字面量**和**使用 `const` 关键字声明的常量**。

**1. 字面量**

字面量用于表达源码中的固定值。字面量一旦被定义，其值就不会改变，因此可称为常量。ArkTS 中常见的字面量：

1. 数字字面量：如 `1`、`2`、`3`。
2. 字符串字面量：如 `'用户名'`、`"密码"`。
3. 布尔字面量：如 `true`、`false`。
4. 数组字面量：如 `[1, 2, 3]`。
5. 对象字面量：如 `{ username: '小智', password: '123456' }`。

**2. 使用 `const` 关键字声明的常量**

- 使用 `const` 关键字声明的常量类似于变量，但**它的值不能发生改变**。
- 为方便与变量区分，习惯上将常量的名称设置为**全大写**。
- `const` 关键字随 JavaScript 的发展在后期加入，并沿用到 ArkTS。它在声明语法基础上增加了“使变量值保持不变”的语法约束，因此这种常量可理解为**“不可变的变量”**。
- 历史原因：在不需要区分变量和常量的语境下，“变量”一词也笼统地包含使用 `const` 声明的常量。

**使用示例：**

```typescript
const STUDENT: string = '小明';
console.log(STUDENT);
// 输出结果：小明
```

**注意**：当 `const` 常量的值是数组、对象时，数组的元素、对象的成员是可以改变的，但**常量本身不能被重新赋值**。

```typescript
// const 修饰数组
const numbers: number[] = [1, 2, 3];
// 可以修改数组内容
numbers[0] = 10;
// 错误：不能给const 常量重新赋值
// numbers = [5, 6, 7];
```

### 2.3.3 数据类型

ArkTS 中常用的数据类型有：

- `string`（字符串）
- `number`（数字）
- `boolean`（布尔）
- `null`（空）
- `void`（空）
- `undefined`（未定义）
- `object`（对象）

**1. string（字符串）**

- 使用**单引号（`'`）**、**双引号（`"`）**或**反引号（`` ` ``）**标注。
- 字符串中的字符可以是 0 个或多个。
- 使用反引号标注的字符串称为**模板字符串**，在模板字符串中通过 `${变量名}` 的方式可以使用变量的值。

```typescript
let stu1: string = '小明';
let stu2: string = "小智";
let introduce: string = `${stu1}和${stu2}是好朋友`;
console.log(stu1);
// 输出结果：小明
console.log(stu2);
// 输出结果：小智
console.log(introduce); // 输出结果：小明和小智是好朋友
```

**转义字符**：以 `\` 开始，常用转义字符如下表：

| 转义字符 | 含义 |
|---------|------|
| `\'` | 单引号 `'` |
| `\"` | 双引号 `"` |
| `` \` `` | 反引号 `` ` `` |
| `\n` | 换行符 |
| `\t` | 水平制表符 |
| `\f` | 换页符 |
| `\b` | 退格符 |

**2. number（数字）**

number 表示数字，分为**整数**、**浮点数**（小数）和**特殊值**。数字前面可加 `-` 表示负数，加 `+` 表示正数（通常省略 `+`）。

**（1）整数**

- 通常使用十进制表示，也可用二进制、八进制、十六进制表示。
- 二进制以 `0b` 开头，八进制以 `0o` 开头，十六进制以 `0x` 开头（`b`、`o`、`x` 不区分大小写）。

```typescript
let bin: number = 0b11010;  // 二进制表示的26
let oct: number = 0o32;     // 八进制表示的26
let dec: number = 26;       // 十进制表示的26
let hex: number = 0x1a;     // 十六进制表示的26
```

**（2）浮点数**

- 类似数学中小数的写法，如 `1.10`。
- 整数和浮点数还可以使用**科学记数法**表示：`E` 或 `e` 后面跟一个数字表示 10 的 n 次幂，如 `2.15E3` 表示 `2.15 × 10³`。

```typescript
// 浮点数
let fNum01: number = -3.12;
let fNum02: number = 3.12;
// 科学记数法
let fNum03: number = 3.14E5;
let fNum04: number = 7.35E-5;
```

**（3）特殊值**

number 类型有 3 个特殊值：

- `Infinity`（无穷大）：计算结果超出最大可表示数字时返回。
- `-Infinity`（无穷小）：计算结果超出最小可表示数字时返回。
- `NaN`（Not a Number，非数字）：进行了非法运算操作时返回。

**3. boolean（布尔）**

- 只有 `true`（真）和 `false`（假）两个值。
- 通常用于表示程序中的逻辑判断结果：`true` 表示事件成功或条件成立，`false` 表示事件失败或条件不成立。
- 例如，判断数字 3 是否大于 2，结果用 boolean 表示为 `true`。

```typescript
let result01: boolean = true;
let result02: Boolean = false;
```

**4. null（空）**

- 表示空，通常用于表示变量未指向任何对象，该类型只有一个 `null` 值。

```typescript
let empty: null = null;
```

**5. void（空）**

- 表示空，通常用于表示函数没有返回值，该类型只有一个 `void` 值。

```typescript
let data: void;
```

**6. undefined（未定义）**

- 当声明的变量还未被赋值时，该变量的值为 `undefined`。

```typescript
let num01: undefined = undefined;
let num02: undefined;
```

**7. object（对象）**

- object 表示对象，是一种**引用数据类型**；其他数据类型属于**基本数据类型**。
- 引用数据类型的特点是：被赋值给变量时，变量保存的是对象的**引用**，同一个对象可以被多个变量引用，从而节省内存空间。

ArkTS 中对象有多种常见形式：

1. **字面量对象**：通过 `{}` 创建，通常用于保存一些数据。
2. **实例**：通过类（class）或构造函数创建的对象。
3. **函数**：对代码进行封装，方便使用（自定义函数、内置函数、方法、构造函数等）。
4. **数组**：用于保存一批相同数据类型的数据。
5. **枚举**：用于预先定义一些值。
6. **内置对象**：预先提供的一些对象。
7. **包装对象**：对基本数据类型自动装箱产生的对象，使其可像对象一样使用。

## 2.4 运算符

### 2.4.1 算术运算符

算术运算符用于对两个数字或变量进行算术运算，与数学中的加减乘除类似。

| 运算符 | 运算 | 示例 | 结果 |
|-------|------|------|------|
| `+` | 加 | `3 + 3` | `6` |
| `-` | 减 | `6 - 3` | `3` |
| `*` | 乘 | `3 * 5` | `15` |
| `/` | 除 | `8 / 2` | `4` |
| `%` | 取模（取余数） | `5 % 7` | `5` |
| `**` | 幂运算 | `4 ** 2` | `16` |
| `++` | 自增（前置） | `a=2; b=++a;` | `a=3; b=3` |
| `++` | 自增（后置） | `a=2; b=a++;` | `a=3; b=2` |
| `--` | 自减（前置） | `a=2; b=--a;` | `a=1; b=1` |
| `--` | 自减（后置） | `a=2; b=a--;` | `a=1; b=2` |

- 自增/自减可放在变量前（前置）或变量后（后置）。
- **前置**返回计算后的结果；**后置**返回计算前的结果。

**示例代码：**

```typescript
let a = 2, b = 2, c = 3, d = 3;
// 自增
console.log('++a的值为', ++a);  // 输出结果：++a的值为3
console.log('a的值为', a);      // 输出结果：a的值为3
console.log('b++的值为', b++);  // 输出结果：b++的值为2
console.log('b的值为', b);      // 输出结果：b的值为3
// 自减
console.log('--c的值为', --c);  // 输出结果：--c的值为2
console.log('c的值为', c);      // 输出结果：c的值为2
console.log('d--的值为', d--);  // 输出结果：d--的值为3
console.log('d的值为', d);      // 输出结果：d的值为2
```

**注意（4 点）：**

1. 四则混合运算遵循“先乘除后加减”。例如 `let a = 2 + 8 - 3 * 2 / 2;` 后，`a` 的值是 `7`。
2. 取模运算结果的正负取决于**被模数**（% 左侧）的正负，与模数无关。例如 `let a = (-8) % 7, b = 8 % (-7);` 后，`a` 为 `-1`，`b` 为 `1`。
3. **尽量避免使用浮点数进行运算**，结果可能存在偏差。例如 `0.1 + 0.2` 的结果是 `0.30000000000000004`。可将小数转整数计算后再转回小数（如乘 10 相加再除以 10 得到 0.3）。
4. `+` 和 `-` 也可表示正数或负数，例如 `+2.1 + -1.1` 结果为 `1`。

### 2.4.2 字符串运算符

- 当 `+` 左右两侧的数据**至少有一个为 `string`** 类型时，`+` 表示字符串运算符，用于字符串拼接。

```typescript
let username = '小智';
let gender = '男';
console.log(username + '，' + gender);
// 输出结果：小智，男
console.log('小智，' + 18);
// 输出结果：小智，18
```

**多学一招：表达式**

- 表达式是一组代码的集合，每个表达式的运行结果都有一个值。
- 变量和各种类型的数据都可构成表达式，最简单的表达式可以是一个变量或字面量。

```typescript
7;                 // 表达式7
a = 7;             // 将表达式7 的值赋值给a
b = a = 7;         // 将表达式“a = 7”的值赋值给b
a + 1;             // 将表达式“a”的值与表达式“1”的值相加
a = a + 1;         // 将表达式“a + 1”的值赋值给a
console.log('' + b); // 将表达式“'' + b”的值作为参数传给console.log()
```

### 2.4.3 赋值运算符

赋值运算符用于将运算符右侧的值赋给左侧的变量。

| 运算符 | 运算 | 示例 | 结果 |
|-------|------|------|------|
| `=` | 赋值 | `a=1, b=2;` | `a=1, b=2` |
| `+=` | 加并赋值 | `a=1, b=2; a+=b;` | `a=3, b=2` |
| `+=` | 字符串拼接并赋值 | `a='abc'; a+='def';` | `a='abcdef'` |
| `-=` | 减并赋值 | `a=4, b=3; a-=b;` | `a=1, b=3` |
| `*=` | 乘并赋值 | `a=4, b=3; a*=b;` | `a=12, b=3` |
| `/=` | 除并赋值 | `a=4, b=2; a/=b;` | `a=2, b=2` |
| `%=` | 取模并赋值 | `a=4, b=3; a%=b;` | `a=1, b=3` |
| `**=` | 幂运算并赋值 | `a=4; a**=2;` | `a=16` |
| `<<=` | 左移位并赋值 | `a=9, b=2; a<<=b;` | `a=36, b=2` |
| `>>=` | 右移位并赋值 | `a=-9, b=2; a>>=b;` | `a=-3, b=2` |
| `>>>=` | 无符号右移位并赋值 | `a=-9, b=2; a>>>=b;` | `a=1073741821, b=2` |
| `&=` | 按位与并赋值 | `a=3, b=9; a&=b;` | `a=1, b=9` |
| `^=` | 按位异或并赋值 | `a=3, b=9; a^=b;` | `a=10, b=9` |
| `\|=` | 按位或并赋值 | `a=3, b=9; a\|=b;` | `a=11, b=9` |

**示例代码：**

```typescript
let num = 5;
num += 3;            // 相当于num = num + 3
console.log('', num);  // 输出结果：8
num -= 4;            // 相当于num = num - 4
console.log('', num);  // 输出结果：4
num *= 2;            // 相当于num = num * 2
console.log('', num);  // 输出结果：8
num /= 2;            // 相当于num = num / 2
console.log('', num);  // 输出结果：4
num %= 2;            // 相当于num = num % 2
console.log('', num);  // 输出结果：0
num **= 2;           // 相当于num = num ** 2
console.log('', num);  // 输出结果：0
```

### 2.4.4 比较运算符

比较运算符用于对两个数据进行比较，返回结果是 `true` 或 `false`。

| 运算符 | 运算 | 示例 | 结果 |
|-------|------|------|------|
| `>` | 大于 | `3 > 2` | `true` |
| `<` | 小于 | `3 < 2` | `false` |
| `>=` | 大于或等于 | `3 >= 2` | `true` |
| `<=` | 小于或等于 | `3 <= 2` | `false` |
| `==` | 等于 | `3 == 3` | `true` |
| `!=` | 不等于 | `3 != 3` | `false` |
| `===` | 全等 | `3 === 3` | `true` |
| `!==` | 不全等 | `3 !== 3` | `false` |

**注意**：
- `==` 和 `!=` 比较不同数据类型时会**自动转换**类型后再比较，而在 ArkTS 中比较不同数据类型会报错。
- `===` 和 `!==` 比较时**不会进行类型转换**。
- **尽可能使用 `===`**。

```typescript
console.log('', 13 > 12);    // true
console.log('', 13 < 12);    // false
console.log('', 13 >= 12);   // true
console.log('', 13 <= 12);   // false
console.log('', 13 == 13);   // true
console.log('', 13 != 13);   // false
console.log('', 13 === 13);  // true
console.log('', 13 !== 13);  // false
```

### 2.4.5 逻辑运算符

逻辑运算符用于多个条件的组合判断。

| 运算符 | 运算 | 示例 | 结果 |
|-------|------|------|------|
| `&&` | 与 | `a && b` | 若 `a` 为 `true`，结果为 `b` 的值；若 `a` 为 `false`，结果为 `a` 的值 |
| `||` | 或 | `a || b` | 若 `a` 为 `true`，结果为 `a` 的值；若 `a` 为 `false`，结果为 `b` 的值 |
| `!` | 非 | `!a` | 若 `a` 为 `true`，结果为 `false`；若 `a` 为 `false`，结果为 `true` |

- 逻辑运算符不是直接判断值是否为 `true`/`false`，而是采用**评估（truthy / falsy）**方式。
- **评估规则**：`false`、`0`、`''`、`null`、`undefined`、`NaN` 这些值被评估为 `false`（假值），其他值被评估为 `true`（真值）。ArkTS 沿用了该规则。

```typescript
// 逻辑“与”
console.log('', 100 && 200);    // 输出结果：200
console.log('', 0 && 123);      // 输出结果：0
console.log('', 3 > 2 && 4 > 3);// 输出结果：true
console.log('', 2 < 1 && 3 > 1);// 输出结果：false
// 逻辑“或”
console.log('', 100 || 200);    // 输出结果：100
console.log('', 0 || 123);      // 输出结果：123
console.log('', 3 > 2 || 4 < 3);// 输出结果：true
console.log('', 2 < 1 || 3 < 1);// 输出结果：false
// 逻辑“非”
console.log('', !1);            // 输出结果：false
console.log('', !0);            // 输出结果：true
```

**短路（Short-circuit）**：使用 `&&` 和 `||` 时按从左到右顺序求值，若通过左侧表达式已能确定最终值，则**不计算右侧表达式**。

```typescript
let aa = 1;
false && aa++;  // &&短路情况
console.log('', aa);  // 输出结果：1
true || aa++;   // ||短路情况
console.log('', aa);  // 输出结果：1
```

### 2.4.6 三元运算符

- 三元运算符包括 `?` 和 `:`，组成三元表达式，根据条件表达式的值决定运行 `?` 后还是 `:` 后的表达式。
- 语法格式：`条件表达式 ? 表达式1 : 表达式2`
  - 条件为 `true` → 返回表达式 1 的结果。
  - 条件为 `false` → 返回表达式 2 的结果。
- 判断 `true`/`false` 同样采用**评估**方式（`false`、`0`、`''`、`null`、`undefined`、`NaN` 被评估为 false）。

```typescript
let age = 18;
let status = age >= 18 ? '已成年' : '未成年';
console.log(status);
// 输出结果：已成年
```

### 2.4.7 数据类型检测运算符

- 使用 `typeof` 运算符检测数据类型，以**字符串形式**返回检测结果。

```typescript
// 第1种语法格式（只能检测单个数据）
typeof 需要进行数据类型检测的数据
// 第2种语法格式（可对表达式进行检测）
typeof(需要进行数据类型检测的数据)
```

```typescript
console.log(typeof 23);      // 输出结果：number
console.log(typeof '水果');   // 输出结果：string
console.log(typeof false);    // 输出结果：boolean
console.log(typeof []);       // 输出结果：object
```

### 2.4.8 运算符优先级

运算符遵循先后运算顺序，称为**优先级**。优先级由上到下递减，同一单元格内运算符优先级相同。

| 结合方向 | 运算符 |
|---------|--------|
| 无 | `()` |
| 左（new 除外） | `.`、`[]`、`new`（有参数，无结合性） |
| 右 | `new`（无参数） |
| 无 | `++`（后置）、`--`（后置） |
| 右 | `!`、`~`、`-`（负数）、`+`（正数）、`++`（前置）、`--`（前置）、`typeof`、`delete` |
| 右 | `**` |
| 左 | `*`、`/`、`%` |
| 左 | `+`、`-` |
| 左 | `<<`、`>>`、`>>>` |
| 左 | `<`、`<=`、`>`、`>=`、`in`、`instanceof` |
| 左 | `==`、`!=`、`===`、`!==` |
| 左 | `&` |
| 左 | `^` |
| 左 | `\|` |
| 左 | `&&` |
| 左 | `||` |
| 右 | `?:` |
| 右 | `=`、`+=`、`-=`、`*=`、`/=`、`%=`、`<<=`、`>>=`、`>>>=`、`&=`、`^=`、`\|=` |
| 左 | `,` |

**说明：**

- 左结合方向：同级运算符从左向右运算；右结合方向：从右向左运算。
- **小括号 `()` 优先级最高**，先计算小括号内的表达式；多个小括号时，最内层优先级最高。

## 2.5 流程控制

### 2.5.1 选择结构

- 选择结构语句（条件判断语句）根据条件表达式进行判断，运行对应代码。
- 常用语句：`if` 语句、`if…else` 语句、`if…else if…else` 语句和 `switch` 语句。
- 所有选择结构语句判断 `true`/`false` 时均采用**评估**方式（`false`、`0`、`''`、`null`、`undefined`、`NaN` 被评估为 false）。

**1. if 语句（单分支 / 条件语句）**

```typescript
if (条件表达式) {
  代码段
}
```

- 如果代码段只有一条语句，可以省略大括号。

**2. if…else 语句（双分支）**

```typescript
if (条件表达式) {
  代码段1
} else {
  代码段2
}
```

**3. if…else if…else 语句（多分支）**

```typescript
if (条件表达式1) {
  代码段1
} else if (条件表达式2) {
  代码段2
}
…
else if (条件表达式n) {
  代码段n
} else {
  代码段n+1
}
```

**示例代码（if / if…else）：**

let age1 = 23;
if (age1 >= 18) {
  console.log('已成年');    // 当age1 >= 18时输出“已成年”
}

let age2 = 17;
if (age2 >= 18) {
  console.log('已成年');
  // 当age2 >= 18时输出“已成年”
} else {
  console.log('未成年');     // 当age2 < 18时输出“未成年”

let score = 78;

switch (表达式) {

**示例说明**：判断变量 `week` 的值，1~6 输出星期一~星期六，0 输出星期日；无匹配 case 则输出“输入错误，请重新输入”。

### 2.5.2 循环结构

- 循环结构用于反复运行某段代码。
- 由循环体和循环条件组成的语句称为**循环语句**；被重复运行的语句称为**循环体**；循环体能否重复运行取决于循环条件。
- ArkTS 提供 3 种循环语句：`for`、`while`、`do…while`。所有循环结构均采用**评估**方式判断 `true`/`false`。

**1. for 语句（循环次数已知）**

```typescript
for (初始化变量; 条件表达式; 操作表达式) {
  循环体
}
```

- ① 初始化变量：用作计数器的变量（通常用 `let` 声明并赋初值）。
- ② 条件表达式：循环是否继续（true 继续，false 结束）。
- ③ 操作表达式：每次循环最后运行，通常用于更新计数器。

**for 语句运行流程（文字描述）**：开始 → 初始化变量 → 条件表达式（true）→ 循环体 → 操作表达式 → 回到条件表达式判断；（false）→ 结束。

**2. while 语句（循环次数未知更适用）**

```typescript
while (条件表达式) {
  循环体
}
```

- 与 for 可相互转换；无法确定循环次数时更适用。
- **运行流程**：开始 → 条件表达式（true）→ 循环体 → 回到条件表达式判断；（false）→ 结束。

**3. do…while 语句**

- 与 while 类似，但 **do…while 先无条件运行一次循环体**，再判断条件表达式。

```typescript
do {
  循环体
} while (条件表达式);
```

- **运行流程**：开始 → 循环体 → 条件表达式（true）→ 回到循环体；（false）→ 结束。

**三种循环对比示例（输出 1~100）：**

```typescript
for (let i = 1; i <= 100; i++) {
  console.log('', i);   // 输出1~100（每次循环输出一个数字）
}

let i = 1;
while (i <= 100) {
  console.log('', i);
  i++;
}

let j = 1;
do {
  console.log('', j);
  j++;
} while (j <= 100)
```

### 2.5.3 跳转结构

- 循环运行中如需跳出本次循环或整个循环，需用到跳转语句。
- 常用跳转语句：`continue` 和 `break`。

**1. continue 语句**

- 在 `for`、`while`、`do…while` 的循环体中使用，用于**立即跳出本次循环**（跳过 `continue` 后的代码，继续下一次循环）。

**2. break 语句**

- 用于**立即跳出整个循环**（结束循环）。

**示例：continue（跳过第 2 个文件，继续上传其余）**

```typescript
let fileList: string[] = ['项目说明.pdf', '程序安装包.exe', '产品图片.png',
  '用户数据.xlsx', '演示视频.mp4', '会议记录.docx'];
for (let index: number = 0; index < fileList.length; index++) {
  if (index === 1) {
    console.info(`${fileList[index]}格式不受支持，已跳过`);
    continue;
  }
  console.info(`${fileList[index]}上传成功`);
}
```

**示例：break（第 2 个文件有风险，立即终止上传任务）**

```typescript
for (let index: number = 0; index < fileList.length; index++) {
  if (index === 1) {
    console.info(`${fileList[index]}存在安全风险，上传任务已终止`);
    break;
  }
  console.info(`${fileList[index]}上传成功`);
}
```

**break 跳转标签（循环嵌套多层跳转）**

- 使用 `break` 跳转到指定标签语句处，需先为语句添加标签。

```typescript
标签名:
  语句

break 标签名;
```

> **注意**：标签语句必须在使用之前定义，否则会出现找不到标签的情况。

**标签语句示例：**

```typescript
outerLoop:
for (let i = 0; i < 10; i++) {
  for (let j = 0; j < 1; j++) {
    if (i == 5) {
      break outerLoop;
    }
    console.log('i = ' + i + ', j = ' + j);
  }
}
```

## 2.6 数组和枚举

### 2.6.1 数组

- 实际开发中常需保存一批相关联的数据并处理。例如保存全班语文成绩求平均分，用多个变量很麻烦低效，用数组则简单高效。
- 数组由 0 个或多个元素组成，每个元素由**索引（下标）**和**值**构成。
  - 索引默认从 **0** 开始依次递增，用于标识元素。
  - 值为元素内容。

> （原文此处为“索引与值对应关系”示意图，未能提取为文字；以 5 个元素 `[55, 65, 75, 85, 95]` 为例，索引分别为 0、1、2、3、4）

**1. 数组的基本使用方法**

通过数组字面量创建数组：

```typescript
[值1, 值2, …]
```

- 中括号 `[]` 中的值即元素，英文逗号分隔；`[]` 内不写内容表示空数组。
- 将数组赋值给变量时，类型可写成 `元素类型[]` 或 `Array<元素类型>`，也可省略（自动推断）。
- 多种元素类型可写成 `(元素类型1 | 元素类型2 | ...)[]` 或 `Array<元素类型1 | 元素类型2 | ...>`。

let scores: number[] = [98, 97, 100, 65];
```

let fruits1: string[] = ['苹果', '香蕉', '橘子'];

// 添加数组中的元素
fruits1[3] = '草莓';
// 修改数组中的元素
fruits1[2] = '菠萝';
```

**2. 二维数组**

- 按维数分一维、二维数组。一维数组元素为非数组类型；二维数组是以**一维数组作为元素**的数组（可表示二维表格、矩阵等）。
- 用 `[]` 嵌套方式创建：

```typescript
[[元素1, 元素2, …], [元素1, 元素2, …], …]
```

**创建与访问示例：**

```typescript
// 创建二维数组
let arr: number[][] = [[89, 98, 80], [95, 83, 85]];

console.log('', arr[1]);     // 输出结果：95,83,85
```

### 2.6.2 枚举

- 开发中常需保存一些预设值（如页面 3 种主题颜色的色值）。使用**枚举**可方便地保存预设值。
- 枚举由一组**命名值**（枚举常量）组成，用于预先定义一些值。

```typescript
// 语法格式1（枚举常量值默认为 0, 1, 2, …）
enum 枚举名1 { 枚举常量名1, 枚举常量名2, 枚举常量名3 }
// 语法格式2（为枚举常量分别赋值）
enum 枚举名2 { 枚举常量名1 = 值1, 枚举常量名2 = 值2, 枚举常量名3 = 值3 }
```

- `enum` 为声明枚举的关键字，建议枚举名和枚举常量名每个单词首字母大写。
- 枚举常量数量可为 0 个或多个。
- 定义了枚举后，使用 `枚举名.枚举常量名` 访问枚举常量的值。

**示例：**

```typescript
enum ColorSet { Red = '#f00', Green = '#0f0', Blue = '#00f' }
console.log(ColorSet.Red);
// 输出结果：#f00
```

## 2.7 函数

### 2.7.1 初识函数

- 函数是实现某个特定功能的一段代码，将包含一条或多条语句的代码块封装起来，使用者只需关心参数和返回值。
- 优势：提高**代码可复用性**，降低**维护难度**。
- ArkTS 中函数分为：
  - **内置函数**：可以直接调用的函数。
  - **自定义函数**：用户自定义实现特定功能的函数，需先定义后调用。

### 2.7.2 自定义函数

定义函数的语法格式：

```typescript
function 函数名(参数1: 类型, 参数2: 类型, …): 返回值类型 {
  函数体
}
```

1. `function`：定义函数的关键字。
2. 函数名：由字母、数字、下划线和 `$` 组成；不能以数字开头，不能是关键字。
3. 参数：外界传给函数的值，数量 0 个或多个，英文逗号分隔。
   - 可选参数用 `参数?: 类型` 或 `参数: 类型 = 默认值` 表示；后者在省略参数时使用默认值，不设默认值则默认 `undefined`。
   - **可选参数必须放在所有非可选参数的后面**。
4. 函数体：函数内所有代码，实现特定功能。需返回值时用 `return` 关键字（如 `return 'a';`）。无返回值的函数调用后返回 `undefined`。
5. `: 返回值类型`：设置返回值类型，可省略（自动推断）；无返回值用 `: void` 表示。

**调用函数（定义与调用顺序不分前后）：**

```typescript
函数名(参数1, 参数2, …);
```

- 传入参数的数量和类型应与定义时相符。
- 用变量保存返回值：`let 变量名: 类型 = 函数名(参数1, 参数2, …);`
- 一个函数的返回值也可作为参数传给另一个函数：`函数名2(函数名1(参数1, 参数2, …))`

**定义与调用示例：**

```typescript
// 定义函数
function sum(num1: number, num2: number): number {
  return num1 + num2;
}
// 调用函数
console.log('', sum(1, 2));
// 输出结果：3
```

**返回值保存与类型断言：**

```typescript
function sum1(num1: number, num2: number) {
  return num1 + num2;
}
let n1 = sum1(1, 2);              // 自动推断
let n2 = sum1(1, 2) as number;   // 类型断言
```

### 2.7.3 将函数作为值使用

- ArkTS 中函数可以作为值使用：作为**变量值、参数值、返回值或数组元素值**等。
- 可以设置类型，也可省略（自动推断）。
- 设置类型时，函数类型写为 `(参数1: 类型, 参数2: 类型, …) => 返回值类型`；可用 `type` 关键字定义自定义类型：`type 类型名 = 类型;`

**将函数作为变量值：**

```typescript
function func(num1: number, num2: number) {
  return num1 + num2;
}
let s1 = func;                                       // 自动推断类型
let s2: (num1: number, num2: number) => number = func; // 设置类型
type T = (num1: number, num2: number) => number;
let s3: T = func;                                    // 设置自定义的类型
console.log('', s1(1, 2));  // 输出结果：3
console.log('', s2(1, 2));  // 输出结果：3
console.log('', s3(1, 2));  // 输出结果：3
```

**将函数作为参数值、返回值、数组元素值：**

```typescript
// 将函数作为参数值
type T1 = (num1: number, num2: number) => number;
function fn(sum: T1) {
  return sum;   // 将函数作为返回值
}
function sum(num1: number, num2: number) {
  return num1 + num2;
}
console.log('', fn(sum)(1, 2)); // 输出结果：3

// 将函数作为数组元素值
function sumFn(num1: number, num2: number) {
  return num1 + num2;
}
let arr1 = [sumFn];
console.log('', arr1[0](1, 2)); // 输出结果：3
```

**回调函数（callback）**：在一个函数中调用通过参数传过来的函数，该函数称为回调函数。

```typescript
type T2 = (num1: number, num2: number) => number;
function func1(num1: number, num2: number) {
  return num1 + num2;
}
function sumFn1(sum: T2, num1: number, num2: number) {
  return sum(num1, num2);
}
console.log('', sumFn1(func1, 1, 2)); // 输出结果：3
```

### 2.7.4 箭头函数

- 箭头函数是一种简化的定义函数的语法，可作为表达式的一部分使用，特点是有 `=>` 箭头。
- 通常小括号放参数，后跟 `=>`，再跟 `{}`（函数体）。

```typescript
(参数1: 类型, 参数2: 类型, …): 返回值类型 => {
  函数体
}
```

- 赋给变量后，通过 `变量名()` 调用。

**基本用法：**

```typescript
let sum3 = (num1: number, num2: number) => {
  return num1 + num2;
};
console.log('', sum3(1, 2)); // 输出结果：3
```

**简化写法**：函数体只有一条语句且该语句运行结果就是返回值时，可省略大括号和 `return`：

```typescript
let sum4 = (num1: number, num2: number) => num1 + num2;
console.log('', sum4(1, 2)); // 输出结果：3
```

**函数自调用**：箭头函数用 `()` 标识后，可加 `()` 传递参数并调用：

```typescript
((num1: number, num2: number) => {
  console.log('', num1 + num2);
})(1, 2); // 输出结果：3
```

### 2.7.5 常用的内置函数

ArkTS 提供的内置函数包括：

- `parseInt()`
- `parseFloat()`
- `setTimeout()` 和 `setInterval()`
- `clearTimeout()` 和 `clearInterval()`

**1. parseInt()**

- 将给定数据转换为 `number`，并**直接省略小数部分**，返回整数部分。
- 可自动识别进制。

```typescript
console.log('', parseInt('100.56')); // 输出结果：100
console.log('', parseInt('0xF'));    // 输出结果：15
```

**2. parseFloat()**

- 将给定数据转换为 `number` 类型的浮点数。

```typescript
console.log('', parseFloat('100.56')); // 输出结果：100.56
console.log('', parseFloat('314e-2')); // 输出结果：3.14
```

**3. setTimeout() 和 setInterval()**

- `setTimeout()`：设置定时器，达到指定时间后执行代码。第 1 个参数为要执行的代码，第 2 个参数为指定时间（毫秒），返回值为定时器标识。
- `setInterval()`：类似，但以指定时间为周期**重复**执行代码；`setTimeout()` 只执行一次。

```typescript
let timer1 = setTimeout(() => {
  console.log('1秒后输出1次');
}, 1000);
let timer2 = setInterval(() => {
  console.log('每隔1秒输出1次');
}, 1000);
```

- **同步操作**：每个操作按先后顺序依次执行。
- **异步操作**：某个操作不会立即执行，等时机成熟后执行，优势是不阻塞代码流程。
- `setTimeout()` / `setInterval()` 的第 1 个参数中的代码属于**异步操作**：调用这两个函数后立即执行完成，再继续后面的代码，直到到达指定时间才执行内部代码。

**4. clearTimeout() 和 clearInterval()**

- `clearTimeout()`：清除由 `setTimeout()` 设置的定时器。
- `clearInterval()`：清除由 `setInterval()` 设置的定时器。
- 都只有 1 个参数：要清除的定时器标识。清除后定时器代码不再执行。

```typescript
let timer = setInterval(() => {
  console.log('1秒后输出1次');
  clearInterval(timer);
}, 1000);
```

## 2.8 变量的作用域和闭包

### 2.8.1 变量的作用域

- 变量声明后并非可在任意位置使用，可用范围取决于**作用域**。
- 在大括号 `{}` 中使用 `let` 声明的变量称为**块级变量**，具有**块级作用域**，仅在大括号 `{}` 中有效（如 `if`、`for`、`while`、函数等的 `{}`）。

**函数外无法访问函数内变量（错误示例）：**

```typescript
function info() {
  let student = '小智';
}
info();
console.log(student);
// 错误代码
```

**作用域向内传递**（函数内部可访问外部变量，外部不能访问内部变量）：

```typescript
let num1 = 1;
function fn1() {
  let num2 = 2;
  let fn2 = () => {
    console.log('', num1 + num2);
  };
  fn2();
}
fn1();
// 输出结果：3
```

### 2.8.2 闭包

- 当一个函数**访问了外部的变量或函数**时，就会形成**闭包（Closure）**。
- 闭包是由函数和该函数访问的外部变量/函数组成的整体。
- 通过闭包，可由内层函数访问外层函数中的变量和函数，内层函数称为**闭包函数**。
- 当闭包函数作为返回值返回后，只要闭包函数一直被使用，它所访问的变量和函数就始终在内存中。

**示例：统计闭包函数被调用的次数**

```typescript
function fn01() {
  let num = 0;
  return () => {
    ++num;
    console.log(`第${num}次被调用`);
  }
}
let fn02 = fn01();
fn02();  // 输出结果：第1次被调用
fn02();  // 输出结果：第2次被调用
fn02();  // 输出结果：第3次被调用
```

## 本章重点总结

1. **ArkTS 定位**：基于 TypeScript 扩展，禁用 `any`、强化静态检查、专注低运行时开销与高性能，是鸿蒙应用开发主力语言。
2. **输出与注释**：`console.log(参数1, 参数2, …)`（首参须为字符串）；单行 `//`、多行 `/* */`。
3. **变量与常量**：`let` 声明变量，`const` 声明常量（全大写命名，数组/对象内容可变但本身不可重赋值）；不支持 `any`，支持 `类型1 | 类型2` 联合类型。
4. **数据类型**：`string`、`number`、`boolean`、`null`、`void`、`undefined`、`object`；注意 `object` 为引用类型。
5. **运算符**：算术（`%`、`**`、`++/--` 前置后置区别）、字符串拼接 `+`、赋值（含复合赋值）、比较（推荐 `===`）、逻辑（`&& || !` 及短路、真值/假值评估）、三元、typeof、优先级（小括号最高）。
6. **流程控制**：`if` / `if…else` / `if…else if…else` / `switch`；`for` / `while` / `do…while`（do…while 至少执行一次）；`continue`（跳出本次）、`break`（跳出整个，可带标签）。
7. **数组与枚举**：一维/二维数组、索引从 0 起；枚举 `enum` 预定义常量值。
8. **函数**：自定义函数语法；函数可作为变量值/参数值/返回值/数组元素值；箭头函数；内置函数 `parseInt/parseFloat/setTimeout/setInterval/clearTimeout/clearInterval`，理解同步与异步。
9. **作用域与闭包**：块级作用域；闭包 = 函数 + 其访问的外部变量，可使外部变量常驻内存。

## 易错 / 易考点

- **`==` 与 `===` 的区别**：ArkTS 跨类型用 `==` 比较会报错，必须优先使用 `===`（不自动转型）。
- **`any` 被禁用**：ArkTS 不支持 `any`，这是与 TypeScript 的重要区别。
- **`const` 常量 ≠ 完全不可变**：数组元素、对象成员仍可修改，只是常量本身不能重新赋值。
- **自增/自减前置与后置**：`++a` 返回加之后的值，`a++` 返回加之前的值（常考）。
- **浮点数误差**：`0.1 + 0.2 !== 0.3`，应避免直接用浮点数比较/运算，转整数处理。
- **逻辑运算符短路**：`false && 表达式` 右侧不执行；`true || 表达式` 右侧不执行。
- **真值/假值评估**：`false`、`0`、`''`、`null`、`undefined`、`NaN` 在条件/逻辑判断中视为 `false`。
- **`do…while` 与 `while` 区别**：`do…while` 至少执行一次循环体。
- **`switch` 的 `break`**：遗漏 `break` 会贯穿执行后续 case（fall-through）。
- **作用域**：块级作用域下，函数外不能访问函数内 `let` 变量；作用域可向内传递但不能向外。
- **闭包**：内层函数引用外层变量，变量在闭包存活期间常驻内存，易被用于计数器、私有变量等场景。
- **可选参数位置**：可选参数必须放在所有必选参数之后。
- **`parseInt` 与 `parseFloat`**：`parseInt` 去小数部分（非四舍五入），且能识别进制（如 `0xF` → 15）。
